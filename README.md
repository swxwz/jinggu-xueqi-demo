# 青岚问仙：藏锋

一部以小人物成长、轻选择、多结局为核心的中文修仙互动小说试玩

- 在线试玩：https://swxwz.github.io/jinggu-xueqi-demo/
- 单局约 25–35 分钟
- 10 次轻选择，6 个基础结局与 1 个隐藏结局
- 所有主要角色均为成年人

## 本地运行

```bash
npm install
npm run dev
```

静态页面构建：

```bash
npm run build:pages
```

背景音乐 `Village In The Air` 由 Le Mandrill 发布于 OpenGameArt，许可为 CC0
